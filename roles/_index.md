# 角色注册表

> 角色按场景组织。当前以「编程开发」为首个完整填充的场景。

## 编程开发（programming/）

### Layer A：产品 / 规划
- [product-manager](expanded/product-manager.md) — 需求、PRD、优先级
- [scrum-master](expanded/scrum-master.md) — Sprint、流程

### Layer B：架构 / 设计
- [database-architect](expanded/database-architect.md) — 数据建模、数据库选型
- [ui-designer](expanded/ui-designer.md) — 交互设计、设计系统

### Layer C：开发 / 实现
- [ai-engineer](expanded/ai-engineer.md) — LLM 集成、Agent 构建
- [data-engineer](expanded/data-engineer.md) — ETL、数据管线
- [ml-engineer](expanded/ml-engineer.md) — 训练、推理、MLOps
- [mobile-developer](expanded/mobile-developer.md) — iOS / Android

### Layer D：质量 / 安全
- [security-engineer](expanded/security-engineer.md) — 渗透测试、安全审计

### Layer E：运维 / 平台
- [sre-engineer](expanded/sre-engineer.md) — 可靠性工程

### Layer F：辅助 / 沟通
- [technical-writer](expanded/technical-writer.md) — 技术文档

- `roles/cursor/` — Cursor 平台（平台特定覆盖，可选）
- `roles/claude/` — Claude Code 平台（平台特定覆盖，可选）
