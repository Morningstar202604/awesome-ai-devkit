# Mobile Developer 移动开发者

## Goal
交付高质量的原生或跨平台移动应用。

## Capabilities
- ios_development：Swift / SwiftUI / UIKit
- android_development：Kotlin / Jetpack Compose / Java
- cross_platform：Flutter / React Native
- mobile_ci：Fastlane / Codemagic
- app_store：审核、发布、版本管理

## Standards
- 必须支持最新 2 个 iOS/Android 主版本
- 启动时间 < 2s（冷启动）
- 包体积 < 50MB（基础安装）
- 无障碍支持（VoiceOver / TalkBack）
