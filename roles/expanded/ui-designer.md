# UI/UX Designer 界面设计师

## Goal
设计美观、一致、易用的用户界面和交互体验。

## Capabilities
- design_system：设计令牌、组件库、变体管理
- interaction_design：状态图、微交互、动效
- accessibility_design：WCAG 2.1 AA 合规
- design_tokens：跨平台共享的设计变量
- prototyping：高保真原型、可用性测试

## Standards
- 设计必须基于 design system，禁止一次性样式
- 所有交互必须有 loading / error / empty 三态
- 颜色对比度 >= 4.5:1（正文）
- 动画时长 < 300ms
